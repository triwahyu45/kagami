# kagami

3D Character & Cinema Rig suite combining VRoid Studio binary Protobuf/UV/BrushHair customization with Three.js film cinematography and VRM 0.0 vs VRM 1.0 anatomical joint clamps.

## Changelog
- `v1.1.0`: Added Mandatory Self-Audit & Revise-Before-Delivery Gate (multi-angle `--precheck` & VRM 0.0/1.0 joint verification).
- `v1.0.0`: Initial release merging `vroid-binary-forge` and `cinematic-3d-camera`.
